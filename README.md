# Personal Portfolio Website

A responsive personal portfolio website that presents my skills, projects, experience and contact details.

🔗 **Live Demo:** https://kavya-n-biradar.github.io/personal-portfolio
📁 **GitHub Repository:** https://github.com/kavya-n-biradar/personal-portfolio

## Technologies Used
- HTML5
- CSS3 (responsive layout with Grid and Flexbox)
- JavaScript (mobile navigation menu)
- GitHub Pages (hosting)

## Features
- Responsive design for mobile, tablet and desktop
- Sections: About, Skills, Projects, Experience and Contact
- Mobile hamburger menu
- Links to my GitHub and LinkedIn

## Setup Instructions
1. Clone the repository:
   git clone https://github.com/kavya-n-biradar/personal-portfolio.git
2. Open the folder:
   cd personal-portfolio
3. Open `index.html` in any web browser. No installation is needed.

## Project Structure
- `index.html`: page content
- `style.css`: styling and responsive layout
- `script.js`: mobile menu behaviour
